# ASBS Loan Studio V5 Complete
Combines V3 repayment schedule, ROI changes, part-payments, PDF/Excel export and saved cases with V4 EMI Calculator and Supabase authentication. Annual basis is fixed at 365 days.

1. Upload all files/folders to GitHub.
2. Add Streamlit Secrets: `SUPABASE_URL` and `SUPABASE_ANON_KEY`.
3. In Supabase SQL Editor, run `setup.sql` once.
4. Reboot Streamlit.

# ASBS Loan Studio V5.4

- Desktop, laptop, tablet, Android and iPhone breakpoints.
- Columns stack automatically on narrow screens.
- Inputs use 16px text to prevent iPhone Safari auto-zoom.
- Touch-friendly 44-48px buttons and horizontally scrollable data tables/tabs.
